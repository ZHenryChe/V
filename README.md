## What is this

**V** is a short narrative game built in **2 weeks** for **Doki Jam!**, an online game jam — blending simple runner-style mechanics with visual, decision-driven storytelling. You move, you're asked questions, you press buttons, the story bends around your answers.

It started as a 3AM idea. It shipped as a playable prototype. That's the whole story arc, honestly, and it's a decent one.

## Features

- 🏃 Runner-style movement woven into narrative pacing, not bolted on top of it
- 🎮 Button-press decision points tied directly to in-game questions — your input *is* the story branch
- 🎬 Custom scene transitions built on Unity's scene management, so narrative beats change without breaking flow
- ⏱️ Built solo, start to finish, inside a hard 2-week jam deadline

## Built with

- **Engine:** Unity
- **Language:** C#
- **Scope:** Solo project, ~2 weeks

## Why it's structured this way

The core design constraint was time, not scope — so every system here (scene flow, input handling, decision logic) was built to be *just* robust enough to ship a coherent narrative experience inside the deadline, not to be a general-purpose dialogue engine. That tradeoff is intentional and is basically the whole design lesson of doing a game jam.
